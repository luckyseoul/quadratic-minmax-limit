# Goal

Resolve whether `alpha_n = m_n / n^(3/2)` converges, for the quadratic
minimax problem defined in `CORE.md`.

The original MO limit is OPEN. Either a complete convergence proof or a
complete nonconvergence proof answers the question. Identifying a value
is a separate claim and is not required for an existence proof.

No proof architecture is prescribed. In particular, residual (ii), E1,
uniform gap two, Paley optimality, and multiplier-two/three amplification
are not known necessary conditions. The old value-specific plan is
preserved on the artifact branch recorded in `ARTIFACTS.md`.

Completion requires a self-contained, reviewed proof whose actual
conclusion answers the original question. Finite computations, conditional
lemmas, renamed gates, or all-true route checkboxes are not completion.
