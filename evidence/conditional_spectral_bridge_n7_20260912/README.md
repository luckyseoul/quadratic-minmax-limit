# Conditional-cross spectral bridge: exact order-seven witness

Classification: exact finite minimax result for one source and one returned
conditional minimizer.  It is not an all-orders statement and does not
classify every order-seven conditional minimizer.

For the recorded order-seven `Phi(A)=9` source, Soulkiller ran the complete
49-bit CP-SAT cross-signing minimax model against all 16,384 ordered Boolean
pairs using 88 solver workers.  It proved conditional value `21`.  The
returned witness independently replays on the controller with conditional
objective `21`, `beta(B)=21`, and `||B||op=2 sqrt(3)`
(`3.4641016151377544`).

The deterministic remote witness JSON has SHA-256
`280b9a8823cdcbe2e0769ccb500fe8473ca6fb42f2b8ebc49c6dd3563c8cdbe4`.
The shared small-order solver script SHA-256 is
`5827105f967159818531d52b4530a91c567414464cfb34ae8469ce3709782aa3`.

The one-witness normalized operator ratios for the order-5, 6, and 7 probes
are respectively `1.508`, `1.321`, and `1.309`.  This is descriptive finite
data only, not evidence of a proved asymptotic rate.
