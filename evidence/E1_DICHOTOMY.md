## Dichotomy (proved)

For \(A=C\oplus F\) vs \(\rho=1\) conference \(C\):

| Condition | Bound |
|-----------|-------|
| \(s_+\le -1\) | \(\Phi(A)\ge\Phi+2\) |
| \(s_+=0\) | \(\Phi(A)\ge\Phi\) |
| \(s_+=1\) | \(\Phi(A)\ge\Phi-2\) |
| \(s_-\ge 0\) | \(\Phi(A)\ge\Phi\) |

| deep two-sided \(s_+\ge2\), \(s_-\le-2\) | Max± only give \(\le\Phi-4\); need other arguments |

So \(m_n<\Phi-2\) can only come from deep two-sided matrices.
