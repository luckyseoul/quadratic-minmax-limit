# Max+ = polynomial line-sum profiles; and the floor is a class function

**One-line summary.** Two general-p theorems, both proved and shipped as
Prop 15.588 with fail-when-wrong tests: (I) Max+ is exactly the set of tuples
of line-sum profiles that are polynomials of degree <= max(0, k-2) mod p on
the k active square directions — which identifies the repo's unclassified
"full" family as precisely the k >= 4 strata and makes p = 11 computable;
(II) the floor lambda_min(Phi) >= 6 is exactly a positivity statement about
one class function T on Aut(C), reducing an N x N Gram to ~30 numbers.
**No leftover flag flipped. E(1) remains open.**

## I. The profile classification

Setup: index set {inf} u F_q, q = p^2, n = q+1. Every F_p-line F_p*g in F_q
has a well-defined chi-class (chi(t) = 1 for t in F_p^*), so P^1(F_p) splits
into m = (p+1)/2 "square" and m "nonsquare" directions.

**Theorem A (proved, Fourier).** Cy = py iff yhat is supported on {0} union
one chi-class of F_q^*. Row-inf gives sum_x y_x = p y_inf; row u gives
(chi * y)(u) = p y_u - y_inf; transforming and using chi^(c) = chi(c) G gives
yhat(c)(chi(c) G - p) = 0 for c != 0, with G = +-p the Gauss sum. Hence line
sums are flat in exactly one direction class and vary in the other m.

**Theorem B (proved / certified).** With t_j the linear forms cutting the m
varying directions and sigma_j(s) = sum_{t_j(x)=s} y(x):
`p*y(x) = sum_j sigma_j(t_j(x)) - (m-1) y_inf`, so every point sum is
(m-1)y_inf +- p. Max+ is in bijection with profile tuples satisfying: sigma_j
odd, |sigma_j| <= p, sum_s sigma_j(s) = p*y_inf, all point sums in the two
allowed values. Certified: reproduces N = 260 (p=5) and 11452 (p=7) exactly.

**Theorem C (proved). The degree bound.** Write sigma_j = 2*rhohat_j - (p-2)
with rhohat_j an integer lift of rho_j : F_p -> F_p (lift ambiguous only at
rho_j = p-1, where sigma_j = +p or -p — the "flip"). Reducing the point
condition mod p gives sum_j rho_j(t_j(x)) = const on F_p^2. Reduced monomials
of distinct total degree <= p-1 are independent as functions, so for each
d >= 1 the level-d coefficient vector satisfies sum_j c_{j,d} t_j^d = 0.
Powers of distinct linear forms are independent while their number is <= d+1,
so that kernel has dimension max(0, k-d-1) and vanishes for d >= k-1:

> **every k-active y in Max+ has all profiles of degree <= max(0, k-2) mod p**,
> with the level-d coefficients in a (k-d-1)-dimensional kernel.

(k <= m < p, so every degree involved is < p-1 and the reduction is lossless.)

**Theorem D (proved). k = 0 and k = 2 are empty at every p.** At k <= 2 the
profiles are constant mod p, so each sigma_j takes at most the values c_j and
c_j - 2p, the latter only when c_j = p. y is not constant, so some sigma_1
takes both +p and -p; on either slice the point condition forces
sigma_2 = eps (the other branch needs |sigma_2| > p), contradicting activity.

**Theorem E (proved + certified). The strata.**
- k = 1: count m*C(p, (p+1)/2) at eps = +1 — this **is** the repo's 1D family
  n_1d. Verified 30 (p=5), 140 (p=7), 2772 (p=11).
- k = 3: profiles affine; count C(m,3)(p-1)q — this **is** n_{k=3}. Verified
  100, 1176, 24200.
- k >= 4: profiles of degree >= 2. **This is exactly the repo's unclassified
  "full" family.** At p = 7, m = 4 caps k at 4, and the k=4 stratum is
  4410 = 90q at eps = +1 — matching n_full = 90q exactly.

**Theorem F (proved). Translation gauge.** Polarising sum_j w_j t_j^2 = 0
shows translation moves the k=4 linear level by (2 lam w_j t_j(s))_j; the top
kernel vector has full support, so s |-> (w_j t_j(s))_j is onto the
2-dimensional linear-level kernel. Hence every k=4 solution is the translate
of a **unique pure-parabola representative** with linear level 0, and
sum_j u_j^2/(4 w_j) = 0 mod p holds identically on the stratum. Verified on
all 4410 (p=7: 90 reps x 49) and all 58080 (p=11: 480 reps x 121).

## II. The floor as a class function on Aut(C)

Aut = signed automorphisms generated by translations, square multiplications
and signed inversion (s_inf = s_0 = 1, s_x = chi(x)); each is a signed
permutation M with M C M^T = C, so M commutes with C and Aut permutes Max+.

**Theorem G (proved).** Phi commutes with Aut and for every g,
`tr(Phi . pi(g)) = T(g) := (1/N) sum_{y in Max+} <y, g y>^2 - 2n`.
Proof: Phi = (1/N) sum_a v_a v_a^T with v_a = proj_Z(y_a y_a^T);
tr(v v^T A) = v^T A v; pi(g) v_a = v_{g.a}; and 15.586 B gives
<v_a, v_b> = <y_a, y_b>^2 - 2n.

**Corollary H.** With chi_k the character of the k-th Phi-eigenspace,
`T = sum_k lambda_k chi_k` as class functions, so
`lambda_k = <T, chi_k>/<chi_k, chi_k>`.

> **Leftover 1 is exactly: `<T, chi>/<chi, chi> >= 6` on every irreducible
> constituent of Z.**

Z's decomposition into irreducibles is already known for general p (15.278 F,
even Weil representation). So the floor now needs exactly one new object: a
closed form for the class function T — a **2-point** Max+ autocorrelation,
one number per conjugacy class (30 classes at p=5) instead of an N x N Gram.

Certified at p = 5 on the full signed group (order 15600, 30 classes):
the identity holds to 1.4e-12 and the character formula recovers
80/13, 144/13, 176/13 with error 2.5e-14. Theorem G verified at p = 7 on
sampled elements to 9e-13.

## What this does NOT do

- It does not prove the floor. Theorem C reparametrises Max+; Corollary H
  reduces the floor to T. Neither supplies T in closed form.
- No census is offered as a p-law. The p=11 counts are exact enumeration.
  Any p-formula read off them still needs a general-p proof.
- Honest next step: T(g) is a sum over Max+ of a squared pair-span form, so
  the profile classification (Part I) is exactly the tool that could give it
  stratum by stratum. That is the join between the two halves of this note,
  and it is not done.

## Caveat found the hard way

`C(p, m-1) = C(p, m)` identically here (p - m = m - 1), so it is useless as a
fail-when-wrong perturbation of the 1D count; perturb the binomial by two.
