# Entropy-cost sharpening of the compatibility recursion

2026-09-28. Direct advance on the frozen one-vertex extension route.
This sharpens the remaining Banaszczyk/Fourier--Motzkin ancestry obstruction:
the accumulated compatibility cost is controlled by the Shannon entropy of
the pivot-induced ancestry weights, not by raw generation depth.

Let a transformed normalized slab be represented by a binary compatibility
tree whose leaves are original stable slabs

    |x^s.z| < D_s+r.

At an internal compatibility node, after normalizing both parent normals to
infinity norm one, let the positive pivot magnitudes be p,q in (0,1]. The
exact lower-width recurrence is

    w_child
      >= [q w_1+p w_2]/(p+q) - c(p,q),                    (1)

where

    c(p,q)=2pq/(p+q).                                      (2)

(The earlier note replaced c(p,q) by the crude upper bound 1.)

Define the branch weight

    theta=q/(p+q),   1-theta=p/(p+q).                      (3)

Then

    c(p,q)
      =2(p+q) theta(1-theta)
      <=4 theta(1-theta)
      <= h_2(theta),                                       (4)

where h_2 is binary entropy in bits. The last inequality is the standard
pointwise bound

    h_2(t)>=4t(1-t),  0<=t<=1.

## Theorem 1: entropy controls total compatibility cost

The branch weights (3) induce a probability distribution pi on the leaf
OCCURRENCES of the compatibility tree. Then every nonzero transformed child
has normalized half-width

    boxed:
    w >= r + E_pi[D] - H_2(pi).                            (5)

Proof. Give a leaf the pair

    R=D,   C=0.

At an internal node define

    R=theta R_1+(1-theta)R_2,

    C=c(p,q)+theta C_1+(1-theta)C_2.                       (6)

Recurrence (1) gives w>=r+R-C. By induction and (4),

    C
      <=h_2(theta)+theta H_2(pi_1)+(1-theta)H_2(pi_2)
      =H_2(pi),

which proves (5).

Thus the old cost variable K<=generation depth can be replaced by the
generally smaller entropy H_2(pi).

## Theorem 2: deficit-weighted ancestry mass

For the same tree define

    Z_T = sum_(leaf occurrences ell) 2^(-D_ell).            (7)

The Gibbs variational identity gives, for every leaf distribution pi,

    H_2(pi)-E_pi[D] <= log_2 Z_T.                           (8)

Combining (5) and (8),

    boxed:
    w >= r-log_2 Z_T.                                      (9)

Therefore a nonpositive transformed width is possible only if

    boxed:
    Z_T >= 2^r.                                            (10)

This is the new ancestry obstruction.

Each zero-deficit leaf occurrence contributes 1 to Z_T.
A deficit-2 occurrence contributes only 1/4; deficit 4 contributes 1/16;
in general a deficit-D occurrence contributes 2^(-D).

Hence a dangerous deep branch must contain at least 2^r units of
DEFICIT-WEIGHTED ancestral mass, not merely have generation at least r.

At the neutral increment for an exact minimizer,

    r_n=m_n[(1+1/n)^(3/2)-1]=Theta(sqrt(n)),

so every nonpositive compatibility branch requires

    boxed:
    Z_T >= 2^(Theta(sqrt(n))).                              (11)

In particular, an all-zero-deficit dangerous branch requires at least
2^r zero-deficit leaf occurrences.

## Theorem 3: finite-tree closure criterion

If every compatibility tree generated by a chosen elimination order obeys

    Z_T < 2^r,                                              (12)

then every transformed slab retains positive width through the full
elimination. Consequently the transformed system has a Boolean solution,
which is an actual incident sign row a satisfying

    Phi(A extended by a)<F+r.                              (13)

At r=r_n this gives alpha_(n+1)<alpha_n.

More generally use r=r_n+rho_n; if (12) holds for all sufficiently large n
with summable normalized excess, the frozen one-vertex argument proves
convergence.

## Why this advances the previous remaining obstruction

The September-25 field-width note reduced the unresolved issue to

    r+R_child-K_child>0,

where K paid one full unit per compatibility generation.

The present theorem replaces this by

    r+E_pi[D]-H_2(pi)>0.                                   (14)

Skew-pivot generations are now cheap automatically. Positive-deficit leaves
pay exponentially in the equivalent mass criterion (10). Only a branch with
at least 2^r effective near-edge ancestry can threaten positivity.

The remaining target is therefore no longer "bound arbitrary transform
depth." It is to rule out, or compress, a compatibility tree carrying
2^r deficit-weighted ancestral mass. This is a strictly stronger quantitative
statement than the generation-depth obstruction and it is still directly
inside the one-vertex extension route.
