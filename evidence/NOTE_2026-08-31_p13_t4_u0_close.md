# Proposition 15.745: full-cut energy closes `p=13,t=4,u=0`

This is an **exhaustive finite aggregate certificate** for exactly the
phase-one common-residue branch `u=0` at `p=13,t=4,k=60`.  It does not use a
full coefficient-matrix or Boolean configuration census.  Proposition 15.744
already closes `u=3`; after 15.744 and 15.745 the canonical `p=13,k=60`
remainder is `u in {4,6}`.

```text

```


```text

```

At mean 14 the phase-one floor table permits only `b=2,12`.  The `b=2`
candidate is a two-unit lift above the XNOR baseline, below the sharp
integral-lift floor 10, so the exact row is necessarily the `b=12` literal.

Every general hard row then has `P_L=P0+k_L-1`.  Summing these parallel
counts and using the 61-edge bound gives `P0<=8`; the isolated-chart literal
congruence `P0=5 mod 6` therefore gives `P0=5`.  Hence

```text
hT=17,       P_L=4+k_L=5+e_L.
```

The hard parallel total is 39, leaving opposite parallel total 22.  The
opposite scaled mean is `14Q-22`.  The phase-zero parity and integral-lift
floors exclude `Q<=2`, so the profile is exactly `3^6 4`.

An exact literal row is `(2,2,2,2,2,2)`.  The implementation checks every
three-point evaluation matrix for binary quadratics and every five-point

## The collision-one equality closes `(2,1,1)`

```text

```

check has 792 rows and gives minimum collision one, uniquely up to order at

```text

```

Therefore `C=1`, the duplicate lies in that direction's zero bin, and every
nonzero displacement multiplicity is zero or one.

The new sign premise is checked directly in `F_13^2`, not inserted as a
constant.  For all 14 projective functionals and all six nonzero bins, the
code verifies:

- `chi(-1)=1`, so character signs are well-defined modulo `+/-`;
- every nonzero base-field scalar has extension-field character `+1`, so

with this proved interval gives sharp maximum 66, attained by

